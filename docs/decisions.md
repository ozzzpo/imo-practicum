## На обсуждении

- **Роли.** У Кармеева, Ефимовой и Китаева роли не указаны, project manager не назначен. По курсу нужно по два человека на роль. [Команда](../context/team-02.md).
- **Доска задач.** Предложение — GitHub Issues и Projects в репозитории: задачи связаны с PR, доску упоминает слайд 46.
- **Метрики.** Предложение — основная ROC-AUC, потому что кейс требует вероятность. Дополнительно PR-AUC и recall класса оттока, так как доля ушедших 26,5%. Карточка кейса метрики не задаёт.
- **Разбиение.** Предложение — стратифицированное 80/20 с фиксированным `random_state`, отложенная часть используется только для финальной оценки. На обучающей части — стратифицированная 5-кратная кросс-валидация.
- **Слот промежуточной защиты.** Варианты — 2026-11-27 или 2026-12-04. От слота зависит дата отправки кода.
