## Как сверять источники

- Для точных сроков, задания и порядка сдачи используй актуальные материалы и объявления курса. [Расписание Нетологии](https://netology.ru/profile/program/bhemml-26-pp-1/schedule).
- Для конкретных устных требований открывай вебинар по таймкоду из саммари. Транскрипции экспортированы GigaAMGUI. Имена, числа и технические термины могут быть распознаны с ошибками.
- Демонстрацию EDA и показанный код сверяй с исходным видео. В саммари отмечены места для визуальной проверки.
- Договорённости команды фиксируй отдельно. [Документация команды](../docs/README.md).
