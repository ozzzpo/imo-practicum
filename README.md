# Проектный практикум 1 · команда 2

Команда 2 работает над кейсом 2 «Прогнозирование оттока абонентов телеком-оператора». Задача — оценить вероятность ухода абонента и выделить ключевые факторы риска.

Ближайший этап — первичный EDA своего датасета к паре **13 ноября 2026 года** по исходному расписанию курса. [Кейс №2](context/case-02.md) · [Требования и даты](context/requirements.md).

## Структура монорепозитория

| Папка | Что хранится |
|---|---|
| [`context/`](context/README.md) | Задание, исходные материалы курса, конспекты, оценивание и сроки |
| `context/notebooks/` | Ноутбуки с занятий |
| [`docs/`](docs/README.md) | План команды, распределение работ и проектные решения |
| `notebooks/` | Разведочный анализ и эксперименты команды |
| `src/` | Переиспользуемый код подготовки данных, обучения и оценки |
| `tests/` | Проверки преобразований данных и другого переиспользуемого кода |
| [`data/`](data/README.md) | Инструкция получения данных и локальное рабочее хранилище |
| `reports/` | Графики, отчёты и материалы промежуточной и итоговой защит |

Для погружения в проект начни с [карты контекста](context/README.md).
