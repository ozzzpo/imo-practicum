# Что такое φk (phi-k) и как читать матрицу корреляций φk

## Что такое φk

**φk** — коэффициент корреляции, который работает **для любых типов переменных**: числовых, категориальных и бинарных одновременно. Разработан в CERN (описан в статье *«A new correlation coefficient between categorical, ordinal and interval variables with Pearson characteristics»*, 2018), реализован в Python-библиотеке `phik`.

### Зачем он нужен

Классические коэффициенты ограничены по типам пар:

| Пара признаков | Классическая мера |
|---|---|
| числовая ↔ числовая | Pearson, Spearman |
| бинарная ↔ бинарная | Phi, Cramér's V |
| категориальная ↔ категориальная | Cramér's V, Theil's U |
| числовая ↔ категориальная | классики нет — вот тут φk |

В датасете Telco из 20 признаков только 3–4 числовых, остальные категориальные. Обычная матрица Pearson охватила бы лишь угол таблицы, а φk считает **все пары сразу** — поэтому он использован в ноутбуке `notebooks/semenov_vadim.ipynb`.

### Отличия от похожих мер

- В отличие от Cramér's V, φk **учитывает порядок** в данных (ordinal): он знает, что «Two year» больше «Month-to-month», а 72 месяца больше 1.
- Это не просто косметика: без учёта порядка связь срока договора с оттоком занижалась бы.
- Для чисто числовых пар результат близок к Pearson по модулю.

## Как читать матрицу

Это квадратная таблица, где на пересечении строки X и столбца Y стоит коэффициент связи между ними:

- **Диапазон:** от **0 до 1** (знак не показывают; направление связи из матрицы не видно — только сила).
- **0** — признаки не связаны.
- **1** — полная функциональная зависимость (один признак полностью определяется другим).
- **Диагональ всегда = 1** — каждый признак полностью коррелирует сам с собой.

Ориентировочная шкала интерпретации (аналогична |Pearson|):

| Значение φk | Связь |
|---|---|
| < 0,1 | практически нет |
| 0,1–0,3 | слабая |
| 0,3–0,5 | умеренная |
| 0,5–0,7 | сильная |
| > 0,7 | очень сильная — думать об избыточности признаков |

## На примере датасета Telco Customer Churn

В матрице из ноутбука `notebooks/semenov_vadim.ipynb` (раздел 6):

- **`tenure` ↔ `TotalCharges` ≈ 0,83** — очень сильная связь: накопленные начисления почти линейно растут со сроком жизни. Признаки избыточны → при моделировании риск мультиколлинеарности, имеет смысл оставить один или использовать регуляризацию.
- **`Contract` ↔ `Churn` ≈ 0,4** — одна из самых сильных связей с целевой: тип договора — главный предиктор оттока.
- **`OnlineSecurity`, `TechSupport` ↔ `Churn` ~ 0,3** — умеренная связь: отсутствие защитных услуг повышает риск ухода.

Важно: высокий φk с `Churn` — это **ассоциация, а не причинность**. И матрица не говорит, кто уходит чаще (для направления смотрим barplot доли оттока по категориям из раздела 5 ноутбука).

## Практические правила чтения

1. Прячем диагональ и дубли (матрица симметрична).
2. Ищем ячейки > 0,7 среди **признаков** — признак мультиколлинеарности.
3. Смотрим топ-связи с **целевой** `Churn` — кандидаты в сильные предикторы.
4. `customerID` из анализа исключаем — идентификатор не несёт смысловой связи.

## Код в ноутбуке

```python
import phik

interval_cols = ['SeniorCitizen', 'tenure', 'MonthlyCharges', 'TotalCharges']
phik_matrix = df.drop(columns='customerID').phik_matrix(interval_cols=interval_cols)

plt.figure(figsize=(14, 11))
sns.heatmap(phik_matrix, annot=True, fmt='.2f', cmap='coolwarm', center=0,
            annot_kws={'size': 7})
plt.title('Матрица корреляций $\\phi_k$')
plt.show()
```

Через `interval_cols` числовые признаки объявляются интервальными (непрерывными) — без этого φk будет считать их категориальными и занижать связи.
